IT Partnering

Managed IT

  • Bandwidth-Aware Automation. Intelligent patching and deployments optimised for satellite.
  • 24/7 NOC. Proactive monitoring, incident response, and remote remediation.

02

Sentrify

Cybersecurity

Sentrify is the only cybersecurity service designed specifically for the vessel environment and its connectivity challenges. Managed protection combining world-class technology with maritime expertise.

  • SentinelOne EDR. AI-driven behavioural threat detection and response.
  • WatchGuard UTM. Deep packet inspection, IPS/IDS, gateway antivirus, web & content filtering, application control, and SD-WAN integration.
  • 24/7 vSOC. Continuous fleet-wide threat surveillance and incident response.
  • Compliance Ready. IMO 2021, IACS UR E26/E27, BIMCO, and classification societies.

04

Software as a Service

abela

Purpose-built maritime software, from fleet-wide telemetry and file management to crew internet and ship-and-shore email. Pick what you need, we manage the rest.

  • abela.io. Fleet management platform with real-time dashboard and analytics.
  • abela pulse. Captain-facing bridge dashboard for connectivity, security, and IT health.
  • abela drive. Satellite-optimised file synchronisation built for intermittent connectivity.
  • Dualog Mail / GTMail. Reliable ship-and-shore email optimised for satellite delivery.
  • Crew Internet. Managed crew internet access with pre-paid credits and bandwidth control.

05

Connectivity

Network

Enterprise-grade connectivity spanning SD-WAN, multi-orbit VSAT, LEO, cellular, and L-band, each tailored to your environment with seamless automatic failover.

  • Multi-orbit VSAT. Ku, Ka, C-band with high-throughput GX beams.
  • LEO Constellations. Starlink and OneWeb with sub-50ms latency.
  • LTE/5G Roaming. 140+ countries with multi-SIM hybrid failover.
  • SD-WAN Intelligence. Automatic path selection, link bonding, and policy-based failover.
